Connect your Claude account

Shape uses your own Claude account to write the script that builds each object. You pay Claude directly for what you make.

Get one at console.anthropic.com. It is saved on this computer only, in a file just your account can read, and is never sent anywhere but Claude.

Shape needs Blender to build things. It is free: blender.org/download. Install it and press Save, or type where it is.

Most objects cost a few cents either way. Shape shows what each one cost.
